# Aegis Planning Workspace

This directory stores durable HBTXR plans, baseline snapshots, and work evidence.
It does not authorize active integration, dependency installation, training,
FPGA tools, board access, external artifact mutation, Git push, or release.

- `plans/`: implementation plans.
- `baseline/`: point-in-time baselines.
- `work/`: execution checkpoints and evidence.
- `INDEX.md`: artifact index.
- `BASELINE-GOVERNANCE.md`: baseline and drift rules.
