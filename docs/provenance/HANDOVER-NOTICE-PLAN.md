# HANDOVER Notice Plan

## Before any promotion

1. Identify the original repository, revision, author/copyright holder, and
   exact governing license for every proposed file or behavior.
2. Determine whether code, model weights, and datasets have separate terms.
3. Record whether copying occurred or behavior was independently re-expressed.
4. Preserve required license text, copyright, attribution, modification, and
   paper/dataset notices in the destination distribution.
5. Obtain a named reviewer and date, update the registry rights/status fields,
   and change `promotion_decision` only in a dedicated reviewed commit.

## Current disposition

All registry entries are blocked from promotion. `REFERENCE_ONLY` material may
remain as compact provenance, but it may not be activated. `ADAPT` entries may
inform contract design only; they are not cleared for copying. No notice file
is generated from guesses, and a directory-level LICENSE is not assumed to
cover bundled code, assets, models, or datasets.
