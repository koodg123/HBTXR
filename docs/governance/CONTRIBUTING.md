# Collaboration Rules

- Use `HBTXR` as the Git root; never stage sibling repositories.
- Assign one writer per analysis artifact.
- Use explicit staged path allowlists, never broad `git add -A` for this task.
- Preserve source repository, branch, SHA, and original path.
- Prefer adapters and contract tests over modifying vendored upstream code.
- Mark unavailable tools and evidence honestly.
- Require separate approval for push, artifact-policy changes, licensed tools,
  boards, and active promotion of license-unclear code.
