## 규칙

**계약 문서에는 검증 명령이 있어야 합니다.** 대조되지 않는 계약은 두 구현이 각자
믿는 것을 적어둔 문서일 뿐이고, 그건 계약이 아니라 희망입니다.

가능하면 **레이아웃을 문서가 아니라 데이터가 들고 다니게** 합니다 — AXI-PAYLOAD 의
blob 은 자기 섹션 테이블을 싣고, 양쪽이 그것을 읽습니다. 문서는 그 형식을 설명할 뿐
오프셋의 출처가 아닙니다.
