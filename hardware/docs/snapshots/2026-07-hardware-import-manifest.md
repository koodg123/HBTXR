# Hardware Import Manifest

This document records the HBTXR hardware import from `HGTXR/HGTXR-etri-server/hardware`.

## Source

Primary source:

- `HGTXR/HGTXR-etri-server/hardware`

Not used as active hardware source:

- `HGTXR/HGTXR-home/hardware`
- `HBTXR_v3_0/ref_codes/HW_REF`

- most `pynq/hgtxr/*.hwh`

- `refs/weights/*.npz`

Reference-analysis codebase bundles were not imported into active hardware:

- hardware analysis integrated codebase copies
- ViT accelerator external codebase snapshots

## Rationale

The HBTXR hardware tree should be runnable and reviewable without turning into a bulk archive. Active HLS, Vivado, PYNQ wrapper, tools, tests, and docs were kept. Large artifacts and external hardware references were reduced to selected runtime artifacts or left in references.

The current tree intentionally preserves compatibility paths such as `hls/`, `pynq/`, `refs/`, and `vivado/` because the imported docs and tools directly refer to those paths.
