## 10. Handoff Rule

When writing reports or paper-facing claims, use this hierarchy:

1. Board JSON evidence for deployed runtime claims.
2. Vivado routed full E2E evidence for implementation-level timing/resource claims.
3. HLS csynth full E2E evidence for no-board design-space claims.
4. Mode-profile HLS/Vivado evidence only for proxy target exploration.
5. SW/CSim evidence only for algorithmic or numerical correctness claims.

Do not collapse levels 2-4 into board or full E2E runtime claims.
