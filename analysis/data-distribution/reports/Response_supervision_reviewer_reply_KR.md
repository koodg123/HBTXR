# Response to Reviewer — Supervision(Frame/Event Interpolation)의 정당성

**Comment.** 학습 단계에서 TimeLens-XL 프레임 보간과 이벤트 보간으로 생성한 supervision을 사용하는데, (i) 이러한 데이터 증강이 왜 필요한지, (ii) 이 증강이 정확도 평가를 편향(자기일관성에 의한 과대평가)시키지는 않는지 설명해 주기 바랍니다.

**Response.**
검토자님의 지적에 감사드립니다. 본 증강의 동기와 타당성, 그리고 평가 공정성 확보 방안을 데이터 분포 근거와 함께 아래에 상세히 설명드리고, 관련 내용을 개정본 Sec. [X](Fig. R3–R5, Table R6)에 추가하였습니다.

먼저 증강이 필요한 이유는 프레임 스트림의 시간해상도 한계에서 비롯됩니다. 본 데이터셋의 프레임은 25 Hz(40 ms 간격)로 취득되며, 우리는 표준 I-VT 방식에 따라 동공 중심의 인접-프레임 속도(px/s)를 판정 물리량으로, saccade-세션 속도분포의 90퍼센타일인 493 px/s를 임계로 사용합니다. 그러나 인간의 saccade는 약 30–80 ms 동안 지속되는 탄도형 운동이므로, 40 ms 간격에서는 saccade가 한 프레임과 다음 프레임 *사이*에서 시작·종료되어 두 표본 모두 출발·정착 위치에 가깝게 찍힙니다. 그 결과 인접-프레임 변위가 작아 속도가 임계를 거의 넘지 못하고, saccade는 프레임 표현에서 사실상 "정지"로 나타납니다. 실제로 EV-Eye 전체(48명, 약 1.49 M 프레임)를 4-state(Fixation/Saccade/Smooth/Blink)로 분류하면 **Saccade 비율이 Train·Val·Test 모든 분할에서 0.00 %** 수준이며(Fig. R3), 이러한 클래스 부재 상태에서는 모델이 saccade를 학습할 유효 표본을 갖지 못합니다.

이 0 %가 saccade의 실제 희소성을 뜻하는 것이 아님은 동일 데이터의 이벤트 스트림이 분명히 보여 줍니다. 이벤트 카메라는 동공·홍채 경계가 빠르게 움직일 때 마이크로초 단위로 이벤트를 폭발적으로 발생시키므로, 빠른 운동이 이벤트 밀도의 급증으로 직접 기록됩니다. 원시 이벤트를 20 ms bin으로 모아 레이트 `rate(ev/s)`와 세션 중앙값 `m`을 구하고 `4·m < rate ≤ 12·m`를 Saccade(그 이상은 Blink)로 판정하면, **Saccade가 모든 분할에서 약 8.5 %(Train 8.4 %, Val 8.7 %, Test 8.6 %)** 로 안정적으로 나타납니다(Fig. R4). 즉 saccade는 전체 시간의 약 1/12에 이를 만큼 실제로 빈번하며, **프레임에서 관측된 0 %는 생리학적 사실이 아니라 25 Hz 시간해상도가 초래한 측정 아티팩트**임이 정량적으로 확인됩니다. 동시에 이벤트 버스트는 saccade가 *언제* 발생하는지도 알려 줍니다.

이 두 분포의 대비가 곧 증강의 설계 지침입니다. 모델의 프레임 경로는 saccade 상태를 학습해야 하지만 40 ms 프레임으로는 이를 표현할 수 없고, 이벤트는 saccade가 실재함과 그 발생 구간을 알려 주므로, 우리는 **이벤트 버스트가 가리키는 saccade 구간에 한하여 TimeLens-XL로 프레임을 200 Hz(5 ms)로 보간**합니다(프레임과 이벤트가 동일 DAVIS 클럭을 공유함을 확인하여 시점 정합이 보장됩니다). 간격이 5 ms로 좁혀지면 하나의 saccade가 6–16개의 보간 프레임에 걸쳐 펼쳐져 인접-프레임 속도가 임계를 넘고, 프레임 표현에서도 saccade가 다시 검출되어 그 비율이 **약 9.3 %**[실측치 [TBD]로 확정]로 회복됩니다(Fig. R5, Table R6); Fixation·Smooth·Blink 분포는 거의 변하지 않습니다. 이어서 이벤트 측도 같은 200 Hz 타임라인에 맞추어, 보간 프레임 쌍의 밝기 변화를 임계화(V2E)하여 희소했던 프레임-사이(saccade 전이) 구간에 합성 이벤트를 생성함으로써 두 모달리티를 상호 정합된 형태로 조밀화합니다. 요컨대 본 증강은 없던 사건을 만들어내는 것이 아니라, 이벤트가 그 존재를 증명한 실재 saccade를 프레임·이벤트 표현이 비로소 담을 수 있도록 복원하는 절차입니다.

끝으로 검토자께서 우려하신 평가 편향이 발생하지 않도록, **보간 데이터는 학습 입력의 증강에만 사용**하며 검증·시험과 그 정답(GT)은 보간이 아닌 **원본 EV-Eye 실측(실 프레임·실 이벤트·VGG 수동 라벨)** 에 대해서만 산출합니다. 어떤 정확도 지표도 보간 산출물에 대고 측정하지 않으므로 보간기와의 자기일관성을 성능으로 오인하는 순환 평가는 발생하지 않으며, 이는 정확도 보고 전반(Comment [R2-2])에서 일관되게 적용됩니다. 또한 보간 프레임은 추정값이어서 탄도형 saccade가 다소 평활화될 수 있으므로 이를 saccade의 *정답*으로 사용하지 않고 입력 표현 보강에 국한하며, 학습(실+합성)과 평가(실) 간 분포 차이는 sim-to-real gap으로 별도 보고합니다. 데이터 분할은 subject-independent(Train 1–36 / Test 37–48, Val = {37,40,45,48})를 따릅니다.

*개정 사항: Sec. [X]에 본 분석을 추가하고, Fig. R3(Frame 4-state 분포)·R4(Event 4-state 분포)·R5(보간 후 분포)와 Table R6(판정 물리량·임계·시간해상도·Saccade 비율 요약)을 신설하였으며, 증강과 평가의 분리를 본문에 명시하였습니다.*
