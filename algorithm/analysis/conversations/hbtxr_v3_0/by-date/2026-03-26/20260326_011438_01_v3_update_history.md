## 2026-03-27 Mode2 Target-FPS Interpolation / Synthetic Event Generation Update

### Summary

- `mode2` interpolation was extended from single midpoint synthesis to target-FPS-aware multi-frame synthesis.
- synthetic frame count is now computed automatically from adjacent frame timestamps and `target_fps`, with optional fixed-count override.
- `linear_blend` multi-frame interpolation is operational, and a real `TimeLens` adapter path is now wired into preprocessing.
- `mode2` synthetic-event generation now supports two explicit strategies:
  - `generation_strategy: raw_window | source_pair_average`
  - `average_weighting: mean | alpha`

### Interpolation Changes

- added target-FPS scheduling for synthetic frame generation
  - `target_fps`
  - `fixed_insert`
  - `count_policy: round | floor | ceil`
  - `max_insert`
- interpolation provenance now records:
  - `interp_rank`
  - `interp_insert_count`
  - `interp_target_fps`
  - `interp_count_policy`
- `25 FPS -> 2000 FPS` now resolves to `79` inserted frames per nominal `40 ms` gap.

### TimeLens Backend Changes

- `src/hbtxr/preprocess/interpolation.py`
  - added a runtime adapter for local `TimeLens` inference
  - added checkpoint resolution via `refined_model/attention.bin`
  - added root / checkpoint / device options
- `src/hbtxr/preprocess/canonicalize.py`
  - now forwards `timelens_root`, `timelens_checkpoint`, and `timelens_device`
- `scripts/prepare_ev_eye.py`
  - exposes the same CLI options for one-shot dataset preparation

### Synthetic Event Generation Changes

- `src/hbtxr/data/dataset.py`
  - added `generation_strategy: raw_window | source_pair_average`
  - added `average_weighting: mean | alpha`
  - `raw_window`
    - uses the synthetic timestamp directly and slices the raw event stream at that timestamp
  - `source_pair_average`
    - builds anchor event representations at the interpolation source timestamps `(t0, t1)`
    - synthesizes the final event input by averaging those two anchor tensors
  - `average_weighting: mean`
    - `0.5 * E(t0) + 0.5 * E(t1)`
  - `average_weighting: alpha`
    - `(1 - interp_alpha) * E(t0) + interp_alpha * E(t1)`
- `mode2_stage1.yaml` and `mode2_stage2.yaml`
  - now default to `source_pair_average + alpha`
