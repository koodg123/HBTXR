# Hybrid Configs

Active configs in this directory are expected to work with the current
`algorithm/hybrid/src` API.

- `external/`: HGTXR-derived active runtime and experiment configs.

Historical experiment presets are archived under
`algorithm/archive/imports/legacy_hybrid/configs/`.
The former package-level compatibility config is archived under
`algorithm/archive/imports/legacy_hybrid/configs/package_legacy/`.
