## 읽는 기준

- 첫 문장은 가능한 한 `알고리즘 수준 차이 없음.` 또는 `알고리즘 수준 차이 있음.`으로 시작합니다.
- `차이 없음`은 update rule과 optimizer state semantics가 upstream와 동일하다는 뜻입니다.
- `차이 있음`은 trainer 통합, finite-loader 처리, sampled-parameter path 같은 HBTXR 적응층 때문에 계약 일부가 달라졌다는 뜻입니다.
