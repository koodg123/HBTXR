알고리즘 수준 차이 있음.

- 상류 소스 경로/URL:
  - `https://raw.githubusercontent.com/zyushun/Adam-mini/main/adam_mini/adam_mini.py`
- HBTXR 반영 경로:
  - `src/hbtxr/optim/adam_mini.py`
- 동일하게 유지된 부분:
  - Adam-style, head-wise, neuron-wise, fallback block-wise update를 나누는 Adam-mini 기본 철학과 naming heuristic은 유지했습니다.
- 변경한 부분:
  - distributed/DTensor 전용 분기를 제거했습니다.
  - 고차원 tensor를 `[rows, -1]` 형태로 flatten해서 patch embedding과 convolution weight에도 동작하도록 일반화했습니다.
  - YAML에 `dim`, `n_heads`가 없을 때 HBTXR 모델에서 자동 추론하도록 builder를 추가했습니다.
- benchmark 해석 메모:
  - 공식 대형 transformer 구현을 byte-for-byte 재현한 경로는 아니며, HBTXR 모델에 맞춘 보수적 adaptation입니다.
