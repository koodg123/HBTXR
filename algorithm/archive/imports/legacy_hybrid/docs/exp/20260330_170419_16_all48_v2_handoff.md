# All-48 `v2` Baseline 다른 서버용 handoff

이 문서는 현재 Grounded-SAM ROI-crop 작업을 다른 서버에서 이어서 진행하기 위한 handoff 문서다.

포함 내용:

- 이미 완료된 항목
- git에 반영된 항목
- 로컬 전용이라 수동 복사 또는 재생성이 필요한 항목
- 새 서버에서 가장 먼저 실행해야 할 작업

## 1. 현재 상태 요약

현재 권장 operating point:

- eye stage
  - 더 강한 `v2` eye prompt
- pupil stage
  - 엄격한 prompted crop-local pupil stage
- fallback
  - 기본 비활성

더 넓은 검증이 완료된 범위:

- `48 users`
- `4 official sessions`
- `2 eyes`
- `4 sampled frames per eye-session`

최종 full-sweep 결과:

- `sampled_frames=1536`
- `completed=1506`
- `eye_failed=0`
- `pupil_failed=30`
- `fail_like=28`

상위 해석:

- stage-1 eye ROI는 넓은 sweep 수준에서도 안정화됐다.
- 남은 오차는 아래 항목에 집중되어 있다.
  - blink / near-close에서의 보수적 miss
  - geometry로 경고되는 oversized pupil prediction
  - 작은 eye-ROI escape 일부

## 6. 더 넓은 실행을 재현하는 명령

### full broader `v2` sweep

```bash
.venv/bin/python scripts/run_roi_crop_prompted_preview_batch.py \
  --paths-config configs/paths/ev_eye_groundedsam_paths.json \
  --options-config configs/groundedsam/roi_crop_prompted_pupil_v2_eye_prompted.json \
  --raw-samples-root dataset_session_samples_2/raw_samples/roi_crop_prompted_all48_v2_baseline \
  --workspace-root workspace_session_samples_2/roi_crop_prompted_all48_v2_baseline \
  --logs-root dataset_session_samples_2/logs \
  --sample-count 4 \
  --eye both \
  --device cuda:0
```

### final grouped review build

```bash
.venv/bin/python scripts/review_roi_crop_prompted_batch.py \
  --batch-root workspace_session_samples_2/roi_crop_prompted_all48_v2_baseline \
  --output-root workspace_session_samples_2/roi_crop_prompted_all48_v2_baseline_review_live \
  --overwrite
```

## 7. 현재 결과 해석 규칙

### `pupil_failed`

1차 해석:

- blink / near-close frame에서의 보수적 miss

추가로 반드시 볼 것:

- tiny stage-1 eye ROI
- local glare 또는 dark patch 주변 partial crop

### `fail_like`

1차 해석:

- eye ROI 내부에서 과도하게 큰 pupil geometry

가장 흔한 하위 유형:

- blink / near-close에서 slit 전체를 먹는 over-segmentation
- open-eye에서 iris / interior를 대부분 먹는 over-segmentation
