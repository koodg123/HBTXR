# 문서 구조 안내

이 문서는 `HBTXR_v3_0/docs`의 현재 문서 구조와 분류 원칙을 설명합니다.

## 최상위 구조

- `chat/`
  - 대화 기록, 작업 히스토리, 진행상황 체크리스트, 작업 메모
- `exps/`
  - 실험 진행 상황, 실험 결과 분석, 실험 자원
- `plan/`
  - 버전 업데이트 계획, 전환 계획, 후속 작업 계획
- `prj/`
  - 프로젝트 구조 설명, 데이터셋 구축 파이프라인, 코드/설정 설명, 운영용 안내
- `others/`
  - 위 분류에 바로 속하지 않는 문서, 업데이트 리포트, 논문 초안 및 보관 자료

## 파일명 규칙

- Markdown 문서는 가능한 한 `YYYYMMDD_HHMMSS_원래파일명.md` 형식으로 정리합니다.
- 앞의 타임스탬프는 문서 생성 시점을 빠르게 식별하기 위한 용도입니다.
- 이미지, PDF, TeX, BibTeX 같은 부속 자산은 기존 파일명을 유지할 수 있습니다.

## 하위 분류 원칙

### `chat/`

- 실제 대화 로그
- 작업 이력 누적 기록
- 진행 체크리스트
- 현재 작업 메모

### `exps/`

- 실험 요약 및 결과 분석 문서
- 실험 진행 기록 문서
- `progress/` 하위 폴더의 진행 로그
- `resources/` 하위 폴더의 실험 이미지/manifest 자산

### `plan/`

- 버전별 업데이트 계획
- 데이터셋/ROI/학습 파이프라인 전환 계획
- 후속 구현 TODO와 마일스톤

### `prj/`

- 저장소 구조와 모듈 관계 설명
- 데이터셋 생성 및 전처리 파이프라인 설명
- 모델/헤드/loss/config 설명
- 현재 코드베이스를 운영할 때 먼저 읽어야 하는 문서
- `optimizers/`, `references/` 같은 심화 자료는 보조 아카이브로 취급

### `others/`

- 구조 개편 보고서, 브랜치 통합 보고서 같은 보조 리포트
- `update/` 하위 폴더의 마이그레이션/통합 기록
- `jetcas/` 하위 폴더의 논문 초안 및 관련 문서
- `analysis/` 하위 폴더의 장문 조사 문서
- `optimizers/` 하위 폴더의 optimizer diff 보관 문서
- `references/` 하위 폴더의 외부 논문/코드 분석 아카이브

## 중복 문서 정리 원칙

- 동일 주제를 여러 브랜치에서 가져온 경우 한국어 정본과 최신 정리본을 우선 유지합니다.
- 영문 초안이나 이전 중간본은 중복으로 판단되면 제거합니다.
- 실험 진행 문서는 가능하면 `exps/` 또는 `exps/progress/`로 모읍니다.
- 길고 세부적인 분석 문서는 `others/analysis/`로 분리합니다.

## 현재 상태

- `docs` 최상위는 `chat`, `exps`, `plan`, `prj`, `others` 구조로 정리되었습니다.
- 중복 주제 문서는 정본 기준으로 병합/정리되었습니다.
- 주요 인덱스 문서는 새 구조 기준으로 다시 정리되었습니다.
