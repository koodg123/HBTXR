- 동일하게 유지된 부분:
  - `SophiaG` optimizer core
  - `update_hessian()`
  - `step(bs=...)`
  - `_single_tensor_sophiag` 내부 tensor update rule
- 변경한 부분:
  - `build_sophia_g_optimizer(...)` builder를 추가했습니다.
  - `hess_interval`, `step_bs_scale`를 `training.optimizer.kwargs`로 노출했습니다.
  - trainer가 현재 supervised `loss_total` 기준으로 `hess_interval`마다 Hessian refresh pass를 수행합니다.
  - upstream의 LLM token-based constant 대신 effective sample batch size 기반 `bs`를 전달합니다.
  - `GradScaler` 환경에서도 refresh loss를 scale하고, `optimizer.update_hessian()` 전에 gradient를 manual unscale 하도록 지원했습니다.
- benchmark 해석 메모:
  - optimizer core는 공식 구현입니다.
  - 다만 Hessian refresh objective는 upstream sampled-token cross-entropy 경로가 아니라 HBTXR supervised objective에 맞게 통합돼 있습니다.
  - 전체 train-loop AMP 검증은 CUDA 실행 여부에 따라 달라지며, 이번 패스에서는 전용 benchmark를 수행하지 않았습니다.
